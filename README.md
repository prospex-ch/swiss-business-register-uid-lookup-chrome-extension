# Swiss Business Register – UID Lookup by Prospex

Chrome extension (Manifest V3) that looks up Swiss companies in the commercial register by UID (`CHE-123.456.789`) or by name. Data comes from the public [Zefix](https://www.zefix.admin.ch) REST API and the SHAB publications it carries. Every card links to the company's profile on [prospex.ch](https://prospex.ch).

| Locale | Store name |
|---|---|
| en (default) | Swiss Business Register – UID Lookup by Prospex |
| de | Handelsregister Schweiz – UID & Firmensuche |
| fr | Registre du commerce suisse – Recherche IDE |
| it | Registro di commercio svizzero – Numero IDI |

## Features

- **UIDs on any page**: valid UIDs (checksum verified) are underlined with a dotted line. Hovering one shows a card with the name, legal form, status (active, in liquidation, deleted), registered office and canton, and the latest SHAB publication. Pages that load content later are covered too. The toggle in the popup turns this off.
- **Right-click lookup**: select a company name or UID, right-click, choose "Look up … in the Swiss commercial register".
- **Toolbar search**: name or UID, with `Alt+Shift+U` as the default shortcut.

Card links: "Full profile on Prospex" (`https://prospex.ch/company/<che-xxx-xxx-xxx>/` with `utm_source=chrome-extension`, `utm_campaign=uid-lookup`, `utm_content=hover|context-menu|popup`) and the cantonal register excerpt.

## Layout

```
manifest.json            MV3 manifest, names via __MSG_appName__
_locales/{en,de,fr,it}/  every UI string, store name and description
src/background.js        service worker: Zefix calls, session cache, context menu
src/content/content.js   UID detection, hover card, right-click card (shadow DOM)
src/popup/               toolbar search, also served as a tab for pages without a content script
src/lib/uid.js           UID parsing, checksum, formatting
src/lib/zefix.js         Zefix client, normalization, name ranking
src/lib/card.js          the card, shared by all three surfaces
src/lib/prospex.js       Prospex profile URLs
src/data/legal-forms.js  generated by scripts/update-reference-data.sh
store/                   Web Store listing text per locale
```

No build step and no dependencies: the `src/lib` files are classic scripts that attach to `globalThis.SBR`, so the service worker (`importScripts`), content script and popup load the same files.

## Develop

1. `chrome://extensions` → Developer mode → **Load unpacked** → this folder.
2. After editing, click reload on the extension card and refresh the test page.

```bash
npm test            # unit tests (node --test)
npm run test:live   # adds one call to the live Zefix API
npm run zip         # dist/swiss-business-register-uid-lookup-<version>.zip for the Web Store
```

Zefix returns HTTP 500 to the `HeadlessChrome` user agent, so headless browser tests need `--user-agent` set to a regular Chrome string.

## Permissions

| Permission | Why |
|---|---|
| `contextMenus` | the right-click lookup |
| `storage` | the highlight toggle (sync) and a one-hour lookup cache (session) |
| `https://www.zefix.admin.ch/*` | register lookups |
| content script on `http(s)://*/*` | finding UIDs on pages; nothing leaves the page unless a UID is hovered or a lookup is requested |
